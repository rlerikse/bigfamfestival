# Big Fam 1.3.0 — Release Notes

> **Consolidation release.** 1.3.0 was the first version cut after the project
> adopted release-please for automated versioning (see ADR-016). Because there
> were no release tags before it, release-please swept the entire prior history
> of conventional commits into this version's `CHANGELOG.md`. As a result, the
> 1.3.0 changelog is a **historical consolidation**, not a clean "what changed
> since 1.2.2" delta — most of those entries describe foundational work (backend
> API, admin panel, friends system, map, auth, notifications) that had already
> shipped incrementally over the project's life.

## Genuinely new around 1.3.0
- **Account deletion:** users can delete their account, with confirmation prompts.
- **Firebase Functions on Node 22:** upgraded Cloud Functions to Node 22 and firebase-functions v7 for continued support and security updates (under the hood).
