# Big Fam 1.2.2 — Release Notes

## What's New
- **Google Sign-In fixed** — signing in with Google now works reliably on release builds.
- **More reliable Map** — fixed a startup issue that could leave the map blank, and the map now opens centered on the festival grounds.
- **Smoother Schedule** — the schedule shows full hours in a clean 12-hour format, and favoriting no longer bumps your place in the horizontal view.

## Improvements & Fixes
- Fixed a crash that could occur when opening the Schedule tab with an event that had a missing or malformed start time.
- Schedule now remembers your scroll position when you switch between list and grid views.
- Grid view heart icon cleaned up (centered, icon-only) with consistent styling across list and grid.
- Filtering the schedule by Stage/Genre no longer jumps you to the wrong spot.
- "Day over" now scrolls to the last event of the day, not the first.
- Home screen layout fixes: weather/clock sits correctly below the top bar, and the status bar no longer overlaps content on Android.
- Fixed a rendering glitch in the Android top navigation bar.

## Under the Hood
- Tightened Android permissions — removed an unused background-location permission the app doesn't need, so you'll only ever be asked for location while using the map.
- Release-build signing and packaging hardening for smoother store updates.
